# Ghost Town Building Generator – interactive preview

Product page and 3D preview for the **Ghost Town Building Generator**, a procedural Geometry Nodes generator for
weathered small-town and ghost-town buildings in Blender.

- Product page: https://blenderprocedural.github.io/ghost-town-building-generator/
- 3D viewer only: https://blenderprocedural.github.io/ghost-town-building-generator/viewer.html

The 3D model is a texture-baked web version of one preset (Red Commercial); the product itself is fully procedural.

<iframe src="https://blenderprocedural.github.io/ghost-town-building-generator/" width="100%" height="900"
